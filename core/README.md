# studio core

Ядро студии: Go-сервер раздаёт собранный веб-интерфейс, Vite собирает
фронтенд и обеспечивает HMR при разработке.

## Два режима

| Что запустить | Где смотреть | Что это |
| ------------- | ------------ | ------- |
| `npm run dev` | http://localhost:1081 | разработка: HMR, правки sass/js без перезагрузки |
| `go run .` | http://localhost:1080 | продакшен: раздача `dist/` после `npm run build` |

```bash
npm install          # один раз: vite + sass-embedded
npm run dev          # HMR на :1081
npm run build        # сборка в dist/
go run .             # раздача dist/ на :1080
```

Порт Go-сервера можно сменить: `go run . -addr :9090`.
Запросы с `/api` из дев-сервера Vite проксируются на :1080 — когда появится
API ядра, менять ничего не придётся.

## Флаги Go-сервера

| Флаг | Переменная | По умолчанию | Назначение |
| ---- | ---------- | ------------ | ---------- |
| `-addr` | `STUDIO_ADDR` | `:1080` | адрес прослушивания |
| `-web` | `STUDIO_WEB` | `dist`, иначе `html` | каталог с `index.html` |
| `-shutdown-timeout` | — | `5s` | ожидание активных запросов при остановке |

`dist/` в `.gitignore`: после клона нужен `npm run build`. Если `dist/` нет,
сервер отдаёт исходники из `html/` и пишет в лог предупреждение — в браузере
такая страница будет без стилей.

## Структура фронтенда

```
html/
├── index.html        каркас: сайдбар разделов + две панели
├── js/app.js         данные чат-клиентов и рендер (сейчас заглушка)
└── sass/
    ├── app.sass      точка входа: @use всех партиалов
    ├── _tokens.sass  цвета, метрики, шрифты
    ├── _base.sass    сброс и базовая типографика
    ├── _layout.sass  сетка страницы, сайдбар
    └── _options.sass список клиентов, форма опций
```

Партиалы с подчёркиванием не собираются в отдельные файлы — это делает sass
сам через `@use`. Файл с точкой входа импортируется из `js/app.js`
(`import '../sass/app.sass'`), поэтому Vite подхватывает изменения стилей и
применяет их на лету.

Настройки чат-клиентов пока живут в `localStorage` — это прототип. Когда будет
API, в `app.js` достаточно заменить `CHAT_CLIENTS` на `fetch('/api/plugins/chat')`.
