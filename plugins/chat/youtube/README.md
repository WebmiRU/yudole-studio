# YouTube chat plugin

Плагин ищет активные прямые эфиры указанного YouTube-канала и читает их чаты через официальный YouTube Data API v3.

## Настройки

- **YouTube API key** — ключ Google Cloud project, где включён YouTube Data API v3. Ключ не нужен до момента подключения к реальному каналу, но без него плагин остаётся в состоянии offline.
- **Канал YouTube** — URL канала (например, https://www.youtube.com/@Paradoxlivechannel), @handle или ID канала вида UC….

Пользовательский OAuth не требуется для чтения доступных публичных live chat. API key передаётся в REST-запросах как параметр key и в gRPC metadata как x-goog-api-key.

## Поиск эфира и квоты

Плагин разрешает @handle в ID канала через channels.list, затем вызывает search.list не чаще одного раза в минуту с фильтрами channelId, type=video и eventType=live. За одну попытку может быть найдено несколько live-видео; их liveStreamingDetails.activeLiveChatId получает один запрос videos.list.

Ищем до 60 раз (около часа, включая задержку между проверками). Если активный чат не найден, поиск останавливается до изменения настроек. Это ограничивает расходы поисковой квоты примерно 60 вызовами search.list на один запуск поиска. У search.list отдельная базовая квота — 100 вызовов в день на Google Cloud project; она общая для всех установок, использующих этот project/API key.

## Чтение чата

Для каждого найденного activeLiveChatId используется gRPC server-streaming метод liveChatMessages.streamList. Новые события приходят по открытому потоку; при обрыве последнее значение nextPageToken используется для возобновления, а сообщения с повторяющимися ID отбрасываются. Переподключения используют задержку с экспоненциальным ростом, чтобы не расходовать квоту в цикле.

Поддерживаются текстовые сообщения, Unicode-эмодзи, Super Chat, Super Stickers и события удаления/отзыва сообщений. Системные события, для которых YouTube не возвращает видимый текст, пропускаются. Поскольку REST/gRPC API отдаёт пользовательский текст и структурированные сведения, плагин сохраняет текст в message.text / message.src и не строит небезопасный HTML из пользовательского содержимого.

## Ограничения

- Только публичные эфиры с доступным live chat; отключённый чат прочитать нельзя.
- Поиск автоматически останавливается после часа без найденного активного чата. Чтобы попробовать заново, измените/сохраните настройки.
- Соединение gRPC открывается заново при сетевых сбоях, и каждый новый streamList учитывается в квоте API. Постоянное чтение не делает REST-запрос на каждое сообщение.
- Нужен ключ с включённым YouTube Data API v3 и подходящими ограничениями API key для server-side запросов.

## Реализация

Потоковые protobuf-типы streamList лежат в internal/ytproto; они сгенерированы из chatstream.proto в проекте codigolandia/live-quest (https://github.com/codigolandia/live-quest) и поставляются с его MIT-лицензией. Плагин использует стандартную библиотеку Go, gRPC и Protocol Buffers.
