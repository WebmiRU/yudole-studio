# Twitch chat plugin

Плагин подключается к Twitch IRC по TLS на `irc.chat.twitch.tv:6697` и запрашивает IRCv3 capabilities:

- `twitch.tv/tags` — теги сообщений, ID пользователей и смайлов;
- `twitch.tv/commands` — расширенные команды, включая удаление сообщений;
- `twitch.tv/membership` — события входа в канал и выхода из него.

## Настройки

- **Каналы** — логины каналов, по одному в строке; допускается префикс `#`.
- **Логин Twitch** — необязательно. Без него входим анонимно, именем вида
  `justinfan1234`: читать такой вход Twitch разрешает всем.
- **OAuth-токен** — необязательно. Нужен, только чтобы отправлять сообщения;
  чтение чата работает и без него.

Итак, для чтения не нужны ни регистрация, ни ключи: единственное обязательное
поле — список каналов.

## Обработка чата

Поддерживаются `PRIVMSG` (включая `/me`), `USERNOTICE` (подписки, рейды и
подобные сообщения — они помечены `notice`, чтобы их было видно, что писал
сервис, а не человек), PING/PONG, переподключение, JOIN/PART и `CLEARMSG`.
IRCv3-теги разбираются с учётом escape-последовательностей.

Twitch emote IDs и offsets преобразуются в изображения CDN. Offsets переводятся
из UTF-16 в UTF-8, поэтому смайлы после emoji и других многобайтных символов
отображаются правильно. Обычный текст остаётся в `message.text`, а HTML с
изображениями передаётся в `message.html`; исходное содержимое сохраняется в
`message.src`. Текст и alt-атрибуты экранируются, ID смайла проверяется перед
построением URL.

## Устойчивость

Соединение считается пропавшим, если от Twitch не пришло ни одной строки за
шесть минут. Twitch сам спрашивает `PING` каждые пять, поэтому столько молчания
не бывает.

Без такой проверки `ReadLine` на молчащем сокете ждал бы вечно: снаружи всё
выглядело бы живым, а чат просто молчал бы — ровно так вставал GoodGame, пока
его поток событий не начали закрывать при обрыве.

Модуль использует только стандартную библиотеку Go и `studio/core/protocol`.
