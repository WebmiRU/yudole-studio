# Twitch chat plugin

Плагин подключается к Twitch IRC по TLS на `irc.chat.twitch.tv:6697` и запрашивает IRCv3 capabilities:

- `twitch.tv/tags` — теги сообщений, ID пользователей и смайлов;
- `twitch.tv/commands` — расширенные команды, включая удаление сообщений;
- `twitch.tv/membership` — события входа в канал и выхода из него.

## Настройки

- **Логин Twitch** — логин аккаунта, от имени которого выдан токен.
- **OAuth-токен** — пользовательский access token со scope `chat:read`. Поддерживаются значения с префиксом `oauth:` и без него.
- **Каналы** — логины каналов, по одному в строке; допускается префикс `#`.

Токен нужен для авторизации в IRC; анонимное подключение не используется.

## Обработка чата

Поддерживаются `PRIVMSG` (включая `/me`), `USERNOTICE` (системные сообщения о подписках и подобных событиях), PING/PONG, переподключение, JOIN/PART и `CLEARMSG`. IRCv3-теги разбираются с учётом escape-последовательностей.

Twitch emote IDs и offsets преобразуются в изображения CDN. Offsets переводятся из UTF-16 в UTF-8, поэтому смайлы после emoji и других многобайтных символов отображаются правильно. Обычный текст остаётся в `message.text`, а HTML с изображениями передаётся в `message.html`; исходное содержимое сохраняется в `message.src`. Текст и alt-атрибуты экранируются, ID смайла проверяется перед построением URL.

Модуль использует только стандартную библиотеку Go и `studio/core/protocol`.
