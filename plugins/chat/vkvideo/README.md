# VK Видео Live chat plugin

Плагин подключает Studio к публичным чатам трансляций на [live.vkvideo.ru](https://live.vkvideo.ru/). Для чтения не нужны аккаунт, OAuth-токен или API-ключ.

## Настройки

В поле **Каналы** можно указать имя канала или ссылку, по одному на строку:

- `paradoxlivechannel`
- `@paradoxlivechannel`
- `https://live.vkvideo.ru/paradoxlivechannel`

Поддерживаются также ссылки со старого домена `vkplay.live`. Плагин сохраняет каналы в нормализованном виде и устраняет дубликаты.

## Как работает

1. Через публичный API `api.live.vkvideo.ru/v1/blog/{channel}` получает идентификатор публичного WebSocket-канала.
2. Открывает соединение с `pubsub.live.vkvideo.ru`, получает токен подключения через `/v1/ws/connect` и выполняет handshake Centrifugo.
3. Подписывается на `public-chat:{id}` и, если доступно, `channel-info:{id}`.
4. Передаёт текстовые сообщения, имена и идентификаторы авторов, события начала/окончания эфира и доступную статистику зрителей. Упоминания и названия смайлов преобразуются в читаемый текст; HTML из содержимого пользователей не генерируется.

Настройки можно менять без перезапуска Studio: плагин отменяет текущую сессию и соединяется заново. Сетевые обрывы обрабатываются переподключением с экспоненциально растущей задержкой до 60 секунд.

## Ограничения

Публичный WebSocket-протокол VK Видео Live не документирован официально и может меняться без предупреждения. Плагин реализует только чтение, не отправляет сообщения и не поддерживает закрытые чаты. Реальное подключение зависит от доступности публичного API и самого чата канала.
