ЗАПУСК
------

1. Распакуйте архив целиком. Не запускайте изнутри архива.
2. Запустите ядро двойным щелчком:
   - Windows: studio.exe
   - Linux:   ./studio
     (если пишет «Permission denied», выполните один раз: chmod +x studio)
3. Откройте в браузере: http://localhost:1080

Пока идёт сборка, окно терминала можно свернуть — программа работает в фоне.
Закрыть: закройте окно терминала либо остановите процесс studio.

При первом запуске откроется страница настроек: выберите чат-клиент,
впишите каналы и нажмите «Сохранить». Живой чат — на http://localhost:1080/chat.

ЧТО ВНУТРИ
-----------

  studio            ядро: веб-интерфейс, настройки и лента чатов
  dist/             собранный интерфейс
  plugins/chat/…    чат-клиенты, отдельной программой каждый
  config.json       настройки. Правьте через страницу, руками не нужно

ЧАТ-КЛИЕНТЫ
-----------

  Twitch      читает чат анонимно: логин и токен не обязательны
  YouTube     ключ не обязателен: без него читается внутренним API
  VK Видео    без авентификации и ключа
  GoodGame    без ключа

Если нужны счётчики зрителей или названия трансляций у Twitch или YouTube,
впишите ключ/токен в настройках плагина — без них работает, но меньше.

ЕСЛИ ЧТО-ТО ПОШЛО НЕ ТАК
-------------------------

Не работает — скорее всего, закрыт порт 1080 или нет доступа в интернет:
чаты читаются извне, без сети плагины молчат.

Страница настроек: http://localhost:1080
Живой чат:        http://localhost:1080/chat
